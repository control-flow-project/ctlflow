# Runtime capability boundaries

Capability admission belongs to the selected adapter, not a model prompt or
a runtime-name guess.

| Capability | Codex | Earendil Pi |
| --- | --- | --- |
| Create/resume exact native history | Implemented | Implemented |
| Zero-model instruction publication | Native developer-item injection | Native custom-entry extension |
| Receipt-backed user input | Exact retained native history interval | Exact active-branch user entry |
| Captured work interruption | Native exact turn | Native in-process run fence and abort |
| Owner questions | Supported native structured requests/features | Native requests and owned question tool |
| Native permission policy | Supported stock options | No emulated Codex-style sandbox |
| Live terminal attachment | Current owned endpoint | Unsupported |
| Parent-death containment of arbitrary tools | Not guaranteed | Not guaranteed |

Only actual advertised settings/features are admitted.
Unsupported versions or model/effort combinations fail; no clamping, terminal
scraping, copied history or alternate backend substitutes for them.
Claude remains unimplemented.
