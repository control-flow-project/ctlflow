# Container release 0.1.22

Published on 2026-10-18 for Linux amd64. This release contains four selectable
crossfire server implementations and their one shared Knex maintenance image.
It contains no fleet image, site branding, provider credentials or domain fleet.

The images are the verified 0.1.22 build from source commit
`401bc39cb0e1ca399056e00c72598cefde9eeb87`, with build-source digest
`6e37a01daca48b95505a427977547130db548614deb1e97568e13cce410fe805`.
Later main-branch documentation/onboarding UI changes are not silently included
in these frozen images. Different image contents require a new release version.
Host attachment uses the matching public npm fleet/fleetd 0.1.22 packages and
the execution host's existing harness/login.

Registry access follows each package's GitHub visibility setting. Private
packages require an authorized host-side GHCR login; public packages permit
anonymous pulls. Publishing an image does not make a new package public.

## Immutable references

The namespace is `ghcr.io/control-flow-project/`. Each image has version tag
`0.1.22`; use its immutable reference for deployment instead of `latest`.

| Image | Registry manifest digest |
| --- | --- |
| `crossfire-node` | `sha256:9a5f800977a5ef5ee1507c9e355de454ae5e576ff84ffbb537427eda86fed8cf` |
| `crossfire-csharp-managed` | `sha256:dbbbf0a5b998041d64ff7fcadead62a11ee84ae867be84f758fc816317048c9a` |
| `crossfire-csharp-nativeaot` | `sha256:f658c1bdaddd30f58edf2d0421ef4b6204f9b2f25254b435a8c3d6c0d975a826` |
| `crossfire-rust` | `sha256:9f3b161da9f47929f938af4859985558e08c81c036b363c1b4da7f55003fcb2e` |
| `crossfire-migrations` | `sha256:a2e3723374b19f386a33d6f8062306df6efc46809228149060cfde60bfc62bc3` |

For example, select the NativeAOT server and matching maintenance image:

```sh
export CROSSFIRE_RUNTIME_IMAGE=ghcr.io/control-flow-project/crossfire-csharp-nativeaot@sha256:f658c1bdaddd30f58edf2d0421ef4b6204f9b2f25254b435a8c3d6c0d975a826
export CROSSFIRE_MIGRATION_IMAGE=ghcr.io/control-flow-project/crossfire-migrations@sha256:a2e3723374b19f386a33d6f8062306df6efc46809228149060cfde60bfc62bc3
docker pull \
  "$CROSSFIRE_RUNTIME_IMAGE"
docker pull \
  "$CROSSFIRE_MIGRATION_IMAGE"
```

The registry manifest digest identifies the uploaded manifest, not Docker's
local configuration ID or the exported archive's root descriptor. Registry
transport may serialize that manifest differently while retaining the exact
tested image configuration and filesystem. All images retain package label 1
and the same version/source labels; the archive package schema remains 2.

Authenticated pulls of all five immutable references were verified on 2026-10-18
against the tested image configuration, platform and release/source labels.
See the [publication verification record](../../../../docs/verification/20261018-ghcr-publication.md)
for the checked access state and verification limits.
