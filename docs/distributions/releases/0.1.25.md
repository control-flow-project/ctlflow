# Container release 0.1.25

Historical release record. Its Node/npm products, access observations and test
results describe this release only. For current artifacts and installation, use
the [0.1.26 inventory](0.1.26.md).

Published and registry-download verified on 3 November 2026. This record describes
publication, not completion of every live deployment.

The coordinated release contains four selectable Linux amd64 crossfire server
images, one shared Knex maintenance image and public Node fleet/fleetd packages.
There is no fleet image, site branding, domain fleet, data or credential in the
generic containers.

Fleet startup restores listeners with retained native histories asleep. Genuine
eligible input wakes native execution; startup and restart do not inject a task.
Bad Bets read-only SQL and shared agent instructions belong to its separate fleet
repository.

## Access

All five packages remain private. Authenticated immutable pulls passed; an
authorized account with package read access is required. Publication does not
change package visibility. Host registry credentials never enter containers.
