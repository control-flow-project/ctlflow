# Container release 0.1.25

Release preparation is in progress. These artifacts have not yet been published.
Do not use this record as a completed publication or deployment receipt.

The release includes Node, C# managed, C# NativeAOT and Rust crossfire servers,
one shared Knex maintenance image, and the public Node fleet/fleetd packages.
There is no fleet container, site branding, domain fleet, research data or
provider credential in the generic images.

Fleet startup and recovery restore listeners with retained native histories
asleep. Only genuine eligible input authorizes a model turn; no synthetic
restart-task reminder is submitted. Analytical SQL in Bad Bets is a separate
fleet-tooling release, not part of the generic ctlflow images.

## Access

GHCR access and immutable references will be recorded after authenticated
publication and pulls. Publication does not itself change package visibility.
Host-side registry credentials must never enter a server or agent container.
